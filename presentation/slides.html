The Problem

Current IDS (Reactive)

  • Binary classification: benign/malicious
  • Analyses each flow independently
  • No temporal awareness
  • Alert fatigue: millions of false positives

Our Approach (Predictive)

  • Multi-stage classification
  • Learns state transitions
  • Forecasts K steps ahead
  • Explainable with SHAP

System Pipeline

PCAP/CSV → Feature Extraction → Window Builder → World Model → K-Step Forecast + SHAP Explainability

World Model Architecture

What is a World Model?

Learns how network states evolve over time

State at time t+1 depends on state at time t:

P(St+1 | St) = LSTM(Sequence of Windows)

Model: LSTM

  • Hidden size: 128
  • Layers: 2 + LayerNorm
  • Dropout: 0.2
  • 6-class output (attack stages)

Training

  • CIC-IDS-2018 dataset
  • 60s windows, 30s slide
  • Temporal train/val/test split
  • AdamW + ReduceLROnPlateau
